## Requirement
1. При пустом названии задачи приложение должно выдавать ошибку: пустое название - пустая строка, U+00A0, U+200B, пробелы, несколько пробелов, табуляция, перевод строки; при ошибке должно выводиться сообщение "Название не может быть пустым", и такая созданная, а не переименованная, задача не отображается на доске.
2. При пустом переименовании должно возвращаться старое название и задача остаётся видимой.
3. Если в конце или в начале названия задачи есть лишние пробелы, U+00A0, табуляция или перевод строки, то они удаляются.
4. Счётчик должен считать только открытые непустые задачи.
5. Уже сохранённые пустые задачи нигде не отображаются.

## Acceptance tests
1. При попытке сохранить пустое название (пустая строка, U+00A0, пробелы, несколько пробелов, табуляция, перевод строки, U+200B), выводится сообщение "Название не может быть пустым", и возвращается старое название. Если же вводится непустое название с пробелами или U+00A0 по краям, то лишние пробелы обрезаются и выводится обрезанное название.
2. Пустая задача, котораяч уже была в исходных данных, не должна отображаться на доске, ни при каких фильтрах, и в первую очередь её надо проверить в фильтре "Открытые".
3. Открытых задач на исходных данных должно быть 1, и это число должно согласоваться со списком открытые.

## Non-goals
Не надо: менять внешний вид доски, добавлять новые функции, обновлять зависимости, удалять пустую задачу, надо исправить её отображение.

## Files in scope
Можно изменять только файлы src/tasks.ts и src/App.tsx, ничего другого менять нельзя.

## Definition of done
Всё работает, если: мои тесты проходят, npm run build завершается без ошибок, счётчик показывает 1, проверены фильтры и переименование, неразрешённые файлы не тронуты.
